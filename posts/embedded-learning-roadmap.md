嵌入式这个方向最大的坑，不是某个知识点难，而是**不知道该按什么顺序学**。网上资料太多太杂，今天看单片机、明天看 Linux，学了半年还在点灯。

这篇文章把我自己走过的路线整理成一条线，每个阶段说清楚：学什么、学到什么程度算过关、以及最容易被跳过但后面一定会补回来的东西。

## 整体路线图

```
C语言基础  →  单片机入门  →  外设驱动  →  通信协议
   ↓                                          ↓
调试能力 ←──────── 项目实战 ←──────── RTOS / 嵌入式Linux
```

注意这张图有两个特点：

- **调试能力和项目实战是交汇点**，不是最后才学的。从点第一颗 LED 开始就要练调试。
- **RTOS 和嵌入式 Linux 是分岔而不是串联**。MCU 方向往 RTOS 走，应用处理器方向往 Linux 走，不必两个都精通。

## 阶段一：C 语言基础（1-2 个月）

这是唯一一个**不能跳过**的阶段。嵌入式 C 和 PC 上的 C 差别很大，重点在后者不会强调的地方。

必须掌握的内容：

| 知识点 | 为什么重要 | 常见误区 |
|---|---|---|
| 指针与多级指针 | 寄存器映射、DMA 缓冲区、链表 | 只会用 `int *p`，见到 `void **` 就懵 |
| 位操作 | 寄存器配置全靠它 | 不理解 `&= ~` 和 `\|=` 的配合 |
| `volatile` | 防止编译器优化掉硬件读写 | 以为加了更安全，到处乱加 |
| `static` / `extern` | 模块化与链接 | 分不清内部链接和外部链接 |
| 结构体与内存对齐 | 协议解析、寄存器组 | 不知道 `sizeof` 为什么不是字段之和 |
| 函数指针 | 回调、驱动注册表 | 语法看不懂就放弃 |

一段典型的寄存器操作代码，这几个特性全在里面：

```c
#include <stdint.h>
#include <stdbool.h>

#define GPIOA_BASE      0x40020000UL
#define GPIOA_MODER     (*(volatile uint32_t *)(GPIOA_BASE + 0x00))
#define GPIOA_ODR       (*(volatile uint32_t *)(GPIOA_BASE + 0x14))

#define LED_PIN         5U
#define MODER_MASK      (0x3UL << (LED_PIN * 2U))
#define MODER_OUTPUT    (0x1UL << (LED_PIN * 2U))

/* 先把引脚配置成推挽输出，再置位点亮 */
static void led_init(void)
{
    GPIOA_MODER &= ~MODER_MASK;     /* 清掉原来的两位 */
    GPIOA_MODER |= MODER_OUTPUT;    /* 写入 01 = 通用输出 */
}

static inline void led_on(void)
{
    GPIOA_ODR |= (1UL << LED_PIN);
}
```

**过关标准**：能不看资料写出上面这段，并解释清楚每个 `UL`、每个 `~` 和 `volatile` 的作用。

如果你现在的水平是"能写 C，但指针和位操作心里没底"，先花两周把这两块补扎实，比急着上单片机划算得多。

## 阶段二：单片机入门（1-2 个月）

选一颗主流芯片入门即可，**不要纠结选型**。STM32F103 或者国产的 GD32、CH32 都可以，生态资料多最重要。

按这个顺序做实验，每个都亲手写一遍：

1. **GPIO 点灯** —— 理解时钟使能、引脚配置、输出电平
2. **按键输入** —— 理解上拉/下拉、消抖、轮询
3. **外部中断** —— 从轮询跨到中断，理解 NVIC
4. **定时器** —— 定时中断、PWM 输出、输入捕获
5. **串口** —— 重定向 `printf`，从此有了调试手段

第 5 步是个分水岭。**有了串口打印，调试效率会有质的变化**，在这之前你只能靠 LED 二进制调试。

一个最小可用的串口重定向：

```c
#include <stdio.h>

/* 让 printf 走串口1，需要先在 Keil 里勾选 Use MicroLIB */
int fputc(int ch, FILE *f)
{
    while (!(USART1->SR & USART_SR_TXE)) {
        /* 等待发送寄存器空 */
    }
    USART1->DR = (uint8_t)ch;
    return ch;
}

/* 简单的分级日志，比裸 printf 好用 */
#define LOG_E(fmt, ...) printf("[E] " fmt "\r\n", ##__VA_ARGS__)
#define LOG_I(fmt, ...) printf("[I] " fmt "\r\n", ##__VA_ARGS__)
```

**过关标准**：能用定时器 + 中断 + 串口，独立做出一个"每隔 1 秒通过串口上报一次按键状态"的小程序。

## 阶段三：外设驱动（2-3 个月）

这个阶段要接触的都是**板级常见外设**，重点不是会调用库函数，而是能看懂数据手册里的时序图。

按优先级排：

- **UART / I2C / SPI** —— 三大总线，必须全掌握，见[另一篇文章](#/article/uart-i2c-spi)
- **ADC / DAC** —— 模拟量采集，注意参考电压和采样时间
- **DMA** —— 摆脱 CPU 搬运数据，串口和 ADC 都用得上
- **Flash / EEPROM** —— 参数掉电保存
- **看门狗** —— 产品级代码必加

这个阶段开始，**手边要有逻辑分析仪**。I2C 不通的时候，抓一次波形比猜半小时快得多。

**过关标准**：拿一颗没见过的传感器（比如 SHT30、MPU6050），只看数据手册就能把驱动写出来。

## 阶段四：RTOS 或嵌入式 Linux（分岔口）

到这里要选方向了。

**走 RTOS（继续 MCU）**，如果：

- 做的是实时性要求高的控制类产品
- 项目里需要多任务并发、任务间通信
- 想深入电机控制、电源管理这类领域

从裸机大循环跨到 RTOS，最大的思维转变是**不能再靠 `delay` 阻塞了**。起步重点：

```c
/* 裸机思维：delay 阻塞，期间什么都干不了 */
void task_sensor_bad(void)
{
    while (1) {
        read_sensor();
        HAL_Delay(1000);        /* CPU 空转一秒 */
    }
}

/* RTOS 思维：让出 CPU，其他任务照常跑 */
void task_sensor_good(void *arg)
{
    for (;;) {
        read_sensor();
        vTaskDelay(pdMS_TO_TICKS(1000));   /* 阻塞期间调度器切走 */
    }
}
```

**走嵌入式 Linux**，如果：

- 目标是网关、路由器、工业 HMI 这类产品
- 想接触驱动开发、内核裁剪
- 团队用的是 Cortex-A 系列的应用处理器

这两个方向的入门门槛差别不小：RTOS 一周能上手，Linux 光是把交叉编译环境搭顺就要花些功夫。

## 贯穿全程：调试能力

这是**最容易被忽视、但决定你天花板**的能力。硬件和软件不一样的地方在于：你没法 `console.log` 一个正在跑的电路，必须借助工具。

建议按这个顺序配置装备（总预算 500 元以内能起步）：

| 工具 | 价格区间 | 解决什么问题 |
|---|---|---|
| USB 转串口 | 10-30 元 | 打印日志，最先买 |
| ST-Link / J-Link | 20-100 元 | 下载调试、单步、看变量 |
| 逻辑分析仪 | 30-100 元 | 抓 I2C/SPI/UART 时序 |
| 万用表 | 50-200 元 | 电压、通断、电流 |
| 示波器（二手） | 500+ 元 | 电源纹波、信号完整性 |

**过关标准**：板子不工作时，能按"电源 → 时钟 → 复位 → 通信"的顺序系统排查，而不是靠换芯片试。

## 常见误区

几个我自己踩过、也见过很多人踩的坑：

1. **收藏了几十 G 教程，一个实验都没做完**。教程看三遍不如自己写一遍，卡住了再回去查。
2. **过早追求"高深"技术**。RTOS 都没用过就在研究内核源码，结果连任务优先级都配不明白。
3. **只用仿真，不碰实物**。Proteus 里跑通的代码，到了真板子上因为上拉电阻没加而挂掉，这种事太常见了。
4. **不写笔记**。嵌入式细节极多，三个月前调通的 I2C 时序，不记下来下次还得重新踩。
5. **不读数据手册**。中文教程只覆盖了别人用到的部分，遇到问题最终还得回到英文手册。

## 一句话总结

**先打牢 C 语言，再选一颗主流 MCU 把外设跑一遍，从第一天起就练调试，最后按职业方向在 RTOS 和 Linux 之间选一条。**

不要横向铺开什么都学，纵向往深挖一条线，其余的用到再补。
