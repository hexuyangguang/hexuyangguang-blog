软件工程师转硬件最难受的一点是：**代码写错了可以改，板子画错了只能重做，一次就是两周**。

这篇文章梳理 PCB 设计的基本流程和布线规则，重点讲新手最容易出问题的几个地方，以及板子回来不工作时该怎么系统排查。

## 一、设计流程

```
需求分析 → 原理图设计 → BOM 选型 → PCB 布局 → 布线 → 
        DRC 检查 → 导出 Gerber → 打样 → 焊接 → 调试
```

大部分时间是花在**布局和布线**上，但**决定成败的是原理图阶段**——引脚接错、电源设计不合理，后面怎么布线都救不回来。

## 二、原理图阶段：几个致命错误

### 2.1 电源设计

这是新手翻车最多的地方。常见问题：

**LDO 压差不够。** AMS1117-3.3 的压差约 1.1V，意味着输入必须 ≥4.4V 才能稳定输出 3.3V。如果用 5V 输入没问题，但**用 3.7V 锂电池供电就不行了**——电池掉到 3.8V 时输出只有 2.7V，MCU 直接复位。

要锂电池供电就换成低压差 LDO（如 TPS7A02，压差 100mV 级）或 DC-DC。

**去耦电容漏了。** 每对 VDD/VSS 引脚都要配一个 100nF 电容，**必须紧贴引脚放置**。另外整个板子再放一到几个 10μF 的储能电容。

```
MCU 电源入口
    │
    ├── 10μF (板级储能)
    │
    ├──┬── 100nF ── VDD1
    │  │
    │  ├── 100nF ── VDD2
    │  │
    │  └── 100nF ── VDD3
   GND
```

漏掉 100nF 的典型现象是"程序跑得慢一点没事，一跑快就死机"——电源纹波让 MCU 内部逻辑出错。

**DC-DC 的电感选型。** 开关频率、饱和电流、直流电阻都要对。电感饱和电流必须大于峰值电流的 1.3 倍，否则会磁饱和导致输出电压崩塌。

### 2.2 引脚复用冲突

画原理图时不看手册的复用表，很容易出现"两个功能抢同一个引脚"。**画完原理图一定要回头核对一遍复用表**，尤其是：

- SWD 调试引脚（PA13/PA14）有没有被复用
- BOOT0/BOOT1 有没有被拉错电平，导致启动模式不对
- 晶振引脚有没有被当普通 IO 用

### 2.3 上拉下拉电阻

| 场景 | 需要 | 阻值 |
|---|---|---|
| I2C 总线 | 必须 | 2.2k~4.7k |
| 复位引脚 | 必须 | 10k 上拉 + 100nF 到地 |
| BOOT0 | 必须 | 10k 下拉（确保从 Flash 启动） |
| 按键 | 建议 | 外部 10k，比内部 40k 更抗干扰 |
| 未使用的引脚 | 建议 | 配成输出或加上下拉，别悬空 |

**未使用的引脚悬空是大忌**。悬空的输入引脚电平不定，会导致输入级电路反复翻转，白白增加功耗（有时能到几毫安），还可能干扰内部逻辑。

## 三、布局：先摆位，再布线

布局决定了布线的难度。**布局做好，布线是水到渠成的事**。

### 3.1 布局原则

1. **先放接口和结构件**。USB、排针、按键、指示灯的位置由外壳决定，先固定它们。
2. **按功能分区**。电源区、模拟区、数字区、射频区分开，不要交错。
3. **核心器件居中**。MCU 放中间，外设环绕，缩短走线。
4. **晶振紧贴 MCU**。走线越短越好，一般不超过 10mm。
5. **去耦电容贴着电源引脚**。这个不商量。
6. **发热器件分散**，别把两个 LDO 挤在一起。

### 3.2 晶振布局的坑

晶振是**最容易出问题又最难查**的部分：

- **走线尽量短且等长**，两条线长度差控制在 5mil 以内
- **晶振下方禁止走任何信号线**，尤其是高速信号
- **周围铺地并打过孔**，形成屏蔽
- **负载电容要匹配**。手册说 12pF 就配 12pF，配错了频率会偏，串口通信会莫名丢数据

一个真实案例：某板子串口在常温下正常，一到冬天就通信失败。查了两周发现是晶振负载电容用了 22pF（手册要求 12pF），频率偏低约 0.3%，常温下勉强够，低温漂移更大就超标了。

## 四、布线：优先级从高到低

不是所有线都一样重要。按这个顺序处理：

### 4.1 电源线：先走，走粗

- **线宽按电流算**。1oz 铜厚下，1mm 线宽大约能承载 1A（温升 10℃ 时）。留足余量，通常按 2 倍算。
- **电源走树状或星型，不要菊花链**。菊花链会让最后一个器件吃到所有前级的压降。
- **换层时多打过孔**。一个 0.3mm 过孔约 0.5A 载流，大电流要打多个。

```
错误（菊花链）:              正确（星型）:
  VCC ─┬─ A ─┬─ B ─┬─ C        VCC ─┬── A
       │     │     │                 ├── B
      GND   GND   GND                └── C
  C 处的压降 = A+B+C 的和
```

### 4.2 地平面：能铺就铺

**双层板顶层铺地、四层板专门一层做完整地平面**，这是最有效的抗干扰手段。

要点：

- **地平面要尽量完整**，不要被走线割裂成孤岛
- 被割裂的地要用**过孔缝合**，让两侧地电位一致
- **模拟地和数字地单点连接**（在 ADC 芯片下方用 0Ω 电阻或磁珠连接），不要大面积连在一起

### 4.3 差分对和高速信号

USB、以太网、CAN 都是差分信号：

- **严格等长**，长度差控制在 5mil 以内
- **等距平行走线**，间距保持恒定
- **阻抗匹配**。USB 差分阻抗要求 90Ω，这需要计算线宽和间距，可以用 PCB 厂家提供的阻抗计算工具
- **少打过孔**，每个过孔都会引入阻抗不连续

### 4.4 时钟和复位

- **时钟线远离模拟信号和高频信号**
- **复位线加滤波电容**（100nF 到地），且走线尽量短
- **复位走线不要和时钟线平行长距离走**，容易耦合干扰导致误复位

## 五、板子回来不工作：系统排查

这是最实用的部分。**按顺序查，不要乱试**。

### 5.1 第一步：目视和万用表（不通电）

**千万不要一上来就上电。**

1. 目视检查焊点：虚焊、连锡、立碑
2. 万用表测 **VCC 对 GND 的电阻**。正常应该是几百欧到几 kΩ（电解电容充电）。
   - **接近 0Ω → 短路，绝对不能上电**
   - **无穷大 → 断路，检查是否漏焊**
3. 检查关键网络的通断：电源、地、复位、晶振

### 5.2 第二步：上电测电源

**限流上电**——用带电流显示的电源，限流设成预期电流的 1.5 倍。如果一上电电流就顶到限流值，立刻断电，说明有短路。

然后依次测：

| 测点 | 预期值 | 异常说明 |
|---|---|---|
| 输入电压 | 5V ±5% | 电源适配器问题 |
| LDO 输出 | 3.3V ±2% | LDO 损坏或负载短路 |
| MCU VDD 各引脚 | 3.3V | 某个引脚电压不对 → 断线 |
| 复位引脚 | 3.3V（工作时） | 一直是 0 → 复位电路问题 |
| BOOT0 | 0V | 不为 0 → 启动模式错 |

### 5.3 第三步：看时钟

用示波器测晶振引脚。**注意：探头会引入电容，可能让本来起振的电路停振**。建议用 10:1 探头，或者测 MCU 的 MCO 输出引脚（如果配了）。

晶振不起振的常见原因：

- 负载电容配错
- 晶振本身损坏（换一个试）
- 起振电阻没加（某些晶振需要串联 1MΩ）
- MCU 的 HSE 驱动能力配置不够

### 5.4 第四步：能不能下载

- **连不上调试器** → SWD 引脚被复用 / 芯片没供电 / 复位一直有效
- **能连上但下载失败** → Flash 保护 / 供电不稳 / 时钟配置错

### 5.5 第五步：程序跑起来后的问题

| 现象 | 可能原因 |
|---|---|
| 上电跑几秒就死 | 电源纹波、看门狗、栈溢出 |
| 常温正常，高温死机 | 某个器件超温、晶振频偏 |
| 有时正常有时不正常 | 虚焊、接触不良、时序临界 |
| 某个外设不工作 | 引脚复用冲突、上拉没加、时钟没使能 |
| 通信偶尔出错 | 信号完整性、上拉阻值、线太长 |

**"时好时坏"类问题一定有物理原因**，不要归结为"玄学"。用示波器抓异常时刻的波形，或者用热风枪/冷冻剂做温度测试，通常能快速定位。

## 六、打样和焊接的建议

- **打样先用嘉立创等快速打样**，5 片几十块钱，两天到。第一版一定要留测试点。
- **首版留足调试余量**：多留几个飞线焊盘、多引几个 GPIO 到排针、电源入口串一个 0Ω 电阻方便测电流。
- **QFN/BGA 封装建议让厂家贴片**，手工焊接良率低，还不容易发现虚焊。
- **焊完先清洗**。助焊剂残留会吸潮导致漏电，尤其是高阻抗的模拟电路。

## 小结

| 阶段 | 最容易出错的 |
|---|---|
| 原理图 | LDO 压差不够；去耦电容漏了；引脚复用冲突；BOOT0 电平错 |
| 布局 | 晶振离 MCU 太远；去耦电容没贴引脚；功能分区混乱 |
| 布线 | 电源线太细；地平面被割裂；差分对不等长 |
| 调试 | 不测短路就上电；不按顺序排查；把时序问题归为玄学 |

硬件调试和软件调试最大的区别是：**软件可以加日志，硬件只能靠仪器**。所以万用表和示波器不是"以后再说"的东西，是必备工具。
